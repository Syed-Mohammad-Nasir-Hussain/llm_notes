# 🚀 Why Tokenization Exists

Large Language Models cannot directly understand:

```text
Books
Articles
Documents
Sentences
```

LLMs process:

```text
Numbers
Vectors
Embeddings
```

So text must be transformed before training.

---

# 🏗️ Data Preparation Pipeline

Input preparation follows:

```text
Raw Text
↓
Tokenization
↓
Token IDs
↓
Vector Embeddings
↓
LLM Training
```

This lecture focuses on:

```text
Tokenization
+
Token IDs
```

Embeddings come later.

# 1️⃣ Step One — Split Text into Tokens

## What is Tokenization?

Definition:

> Breaking text into smaller units called tokens.

Example:

```text
Input:
This is an example
```

↓

```text
This
is
an
example
```

Tokens become the basic units of language.

---

# Simple Visualization

```text

```

Example:

```text

```

↓

```text

```

# Tokenization Using Regular Expressions

Python approach:

```text
re.split()
```

Purpose:

Split text based on:

- Spaces
- Commas
- Periods
- Question Marks
- Symbols

---

# Example

Input:

```text
Hello, world.
```

↓

```text
Hello
,
world
.
```

Every punctuation becomes a token.

---

# Remove White Spaces

Process:

```text
Split
↓
Filter Empty Values
↓
Final Tokens
```

Result:

```text
Hello
,
world
.
```

No unnecessary spaces.

---

# Important Design Decision

Should spaces remain?

Depends.

---

Remove Spaces:

✅ Lower Memory  
✅ Faster Processing

---

Keep Spaces:

✅ Preserve Structure  
✅ Useful for Code

Example:

```python
if x:
    print(x)
```

Spacing matters.

# Problem — Unknown Words

Example:

```text
Hello do you like tea
```

Issue:

```text
Hello
❌ Not in vocabulary
```

Tokenizer fails.

---

# Solution → Special Tokens

Add:

```text
<|unk|>
```

Meaning:

```text
Unknown Word
```

---

Example:

```text
quickly
```

↓

```text
<|unk|>
```

↓

Token ID

# End of Text Token

Another important token:

```text
<|endoftext|>
```

Purpose:

Separate documents.

Example:

```text
Document A
↓
<|endoftext|>
↓
Document B
```

Helps models understand boundaries.

# Additional Special Tokens

## BOS

Beginning of Sequence


---

## EOS

End of Sequence

```text
<eos>
```

Marks ending.

## PAD

Padding Token

```text
<pad>
```

Used for equal-length batches.

# Interesting Observation

GPT models generally:

❌ Do not use Unknown Token  
❌ Rarely use Padding  

Mostly rely on:

```text

```

---

# Why GPT Doesn't Need Unknown Tokens

Because GPT uses:

# Byte Pair Encoding (BPE)

Instead of:

```text
Word
```

Use:

```text
Subwords
```

Example:

```text
chased
```

↓

```text
cha
+
sed
```

This reduces unknown words.
