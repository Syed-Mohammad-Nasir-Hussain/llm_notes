# Zero-Shot vs Few-Shot Learning

---

## Zero-Shot Learning

Definition:

Perform task without examples.

Example:

```text
Translate English to French:

Breakfast
```

↓

```text
Petit déjeuner
```

No support examples provided.

---

## One-Shot Learning

Definition:

Provide one example.

Example:

```text
Sea Otter → Translation Example
↓
Translate Cheese
```

---

## Few-Shot Learning

Definition:

Provide several examples.

Example:

```text
Input
↓
Example 1
Example 2
Example 3
↓
Generate Output
```

---

# Comparison

| Type | Examples Given |
|---|---|
| Zero Shot | None |
| One Shot | One |
| Few Shot | Few |

---

# Important Observation

GPT models are capable of:



```text

```

# Why Called Auto-Regressive?

Because:

```text
Previous Output
↓
Future Input
```

Output becomes input repeatedly.

---

# Why Called Self-Supervised?

Because:

Labels already exist.

Example:

```text
Sentence
↓
Split
↓
Predict Next Word
```

No external labels needed.

# ✨ Emergent Behavior

One of the most surprising concepts.

Definition:

> Ability of the model to perform tasks it was never explicitly trained for.

Examples:

- Translation
- MCQ Generation
- Summarization
- Lesson Planning
- Essay Grading
- Content Creation
