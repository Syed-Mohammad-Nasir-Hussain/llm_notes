# 🏗️ Two Stages of Building an LLM

Building a Large Language Model generally involves:

```text
Pre-training
↓
Fine-tuning
```

These two stages transform raw data into powerful AI systems.

---

# 1️⃣ Pre-training

## Definition

Pre-training means:

> Training an LLM on a huge and diverse dataset.

Goal:

Teach the model general understanding of language.

---

## Why Pre-training Matters

When interacting with ChatGPT:

```text
Ask Question
↓
Model Understands
↓
Model Responds
```

This capability exists because the model has already seen massive amounts of information during training.

---

## Example: GPT Training Data

GPT models were trained using data from sources such as:

- 🌐 Common Crawl
- 📚 Books
- 📝 Web Articles
- 🧠 Wikipedia
- 💬 Reddit Discussions
- 💻 Technical Content

Example scale:

```text
Hundreds of Billions
of Tokens
```

*(Approximate understanding: token ≈ word)*

---

## How Models Learn During Pre-training

Initial objective:

### Next Word Prediction

Example:

```text
The lion is in the ______
```

Model predicts:

```text
forest
```

Repeated billions of times.

---

## Interesting Discovery

Researchers discovered:

Training only for:

```text
Next Word Prediction
```

unexpectedly enables:

- Translation
- Summarization
- Question Answering
- Sentiment Analysis
- Text Generation

This became one of the biggest breakthroughs in AI.

---

# 🧠 Why LLMs Beat Traditional NLP

Traditional NLP:

```text
Task A → Separate Model
Task B → Separate Model
Task C → Separate Model
```

Modern LLM:

```text
One Model
↓
Many Tasks
```

Examples:

- Translation
- MCQ Generation
- Chatbots
- Summaries
- Classification

---

# 2️⃣ Fine-tuning

## Definition

Fine-tuning means:

> Refining a pre-trained model using a smaller domain-specific dataset.

Goal:

Adapt general intelligence into specialized intelligence.

---

## Why Fine-tuning Exists

Pre-trained models:

✅ General knowledge

But companies need:

- Company-specific knowledge
- Domain-specific knowledge
- Private datasets

---

## Example

Airline Chatbot

Question:

```text
What is the ticket price?
```

Generic Model:

❌ Generic answer

Fine-tuned Model:

✅ Airline-specific answer

---

## Real-world Examples

### 📡 Telecom

Fine-tuned customer support systems.

Results:

- Better conversation quality
- Better intent understanding

---

### ⚖️ Legal AI

Models trained using:

- Legal history
- Legal cases
- Legal terminology

Purpose:

Assist lawyers and legal teams.

---

### 🏦 Banking

Companies fine-tune models using:

- Internal documents
- Financial data
- Business knowledge

---

# 🔑 Important Concept

## Foundation Model

Pre-trained model:

```text
Internet Data
↓
Pre-training
↓
Foundation Model
```

Then:

```text
Foundation Model
↓
Fine-tuning
↓
Specialized AI
```

---

# 📊 Complete LLM Pipeline

```text
Large Raw Text Data
↓
Pre-training
↓
Foundation Model
↓
Fine-tuning
↓
Production Applications
```

---

# 📚 Raw Text vs Labelled Data

## Pre-training

Uses:

```text
Unlabelled Text
```

Examples:

- Articles
- Books
- Web Pages

---

## Fine-tuning

Uses:

```text
Labelled Data
```

Examples:

```text
Email
↓
Spam
```

```text
Customer Question
↓
Correct Response
```

---

# 🎯 Types of Fine-tuning

## Instruction Fine-tuning

Teach:

```text
Input
↓
Desired Output
```

Example:

```text
English
↓
French
```

---

## Classification Fine-tuning

Teach:

```text
Input
↓
Category
```

Examples:

- Spam Detection
- Email Classification
- Sentiment Analysis

---

# 💸 Computational Reality

Training large models is expensive.

Example discussed:

```text
GPT-3 Pre-training
≈ Millions of Dollars
```

Requirements:

- GPUs
- Compute Infrastructure
- Massive Data

This explains why many teams use existing foundation models.

---

# 🏢 Industry Pattern

Small Teams:

```text
Use Existing Models
```

Large Companies:

```text
Use Foundation Model
↓
Fine-tune
↓
Deploy
```

---

# ✨ Lecture 3 Final Takeaway

> Pre-training creates general intelligence. Fine-tuning transforms it into domain expertise.

Understanding both stages is essential for building production-grade LLM systems.
